# POS System

## 📌 Descripción
Sistema de punto de venta web para gestión de inventario y ventas en tiempo real.

## 🧠 Arquitectura
- Backend: Spring Boot
- Frontend: Angular (en progreso)
- Base de datos: PostgreSQL

## ⚙️ Tecnologías
- Java 17
- Spring Boot
- PostgreSQL
- Docker (futuro)

## 📂 Estructura
/backend → API REST  
/frontend → interfaz de usuario
